HTML and CSS as part of the Blockfuse Labs Frontend Developer 
Assessment.

[View Live Site](#) *(https://blockfuse-web2-assignments.vercel.app/test1/)*

## 📌 About This Project

This portfolio represents my professional identity as a Junior Cyber 
Analyst and Computer Science student. It was built from scratch in 3 
hours using strictly HTML and CSS — no frameworks, no libraries.

The core philosophy of this project is **Mobile-First Design** — 
built for the smallest screen first, then scaled up using CSS media 
queries for tablet and desktop viewports.

---

## 📱 Features

- **Mobile-First Design** — base CSS targets mobile devices; 
  min-width media queries handle larger viewports
- **Fully Responsive** — adapts fluidly across mobile, tablet, 
  and desktop screen sizes
- **Hamburger Navigation** — functional pure CSS hamburger menu 
  for smaller screens
- **Smooth Scroll** — anchor links for seamless section navigation
- **Complete Sections:**
  - Header with sticky navigation
  - Hero section with name and title
  - About Me
  - Projects & Skills
  - Contact with social links
  - Footer

---

## 📐 Responsive Breakpoints

| Breakpoint | Target |
|---|---|
| Base (default) | Mobile devices |
| min-width: 560px | Small tablets |
| min-width: 830px | Tablets — hamburger replaced by full nav |
| min-width: 1200px | Desktop — hero switches to row layout |
| min-width: 1800px | Large screens — typography scales up |

3. Import your GitHub repository
4. Click Deploy
